# 《遗产融绘 · 魅力高邮》网站改进方案

> 依据：`比赛要求.txt`、`评审指标体系.txt`、`融绘贯通-项目思路.txt`、`高邮调研报告.txt`、`网站设计稿.docx`、`微信图片_20260805194610_55_372.png`（首页目标稿）
> 核心目标：**首页 1:1 还原微信图片设计稿**，全站从"项目汇报页"转型为"多类型遗产数字活化平台"。

---

## 一、现状问题诊断（对比要求文档）

### 1. 首页定位错误 —— 与设计稿要求直接冲突
当前首页（gaoyou-pages/index.html）首屏是**项目汇报风**：
- 首屏大字写着「2026 大学生新文科实践创新大赛 · 文史哲组」「融绘贯通」「多类型遗产系统性保护利用的路径探索与实践」。
- 设计稿第 12 条明确要求：**"这里不需要出现新文科大赛文史哲组""不要加项目两个字"**，否则别人会以为是专为比赛建的页面。
- 结论：首屏必须改为图片中的「遗产融绘 · 魅力高邮」沉浸式数字博物馆风格。

### 2. 板块结构不是"平台"，而是"汇报目录"
现状板块：项目简介 → 实地调研数据分析 → 共生地图 → 调研诊断 → 项目成果 → 页脚。
- 缺：顶部导航、三脉（水之源/田之魂/人之韵）、穿越千年时间轴、研学路线、互动游戏中心、底部守护计划 CTA。
- "实地调研分析"应改为设计稿要求的"现状"；"项目成果"不应出现"项目"字样。

### 3. 首屏无画面、无沉浸感
- 现在是深色渐变抽象背景，无图；设计稿要求"无人机俯瞰高邮湖全景"的动态画面（远景湖面/芦苇/水鸟、中景稻田/鸭群、近景古闸/村民）。
- 首页整体不够生动美观（设计稿第 9 条），需用**实拍照片 + 水乡插画风**重建视觉。

### 4. 地图很好但不是"三维"，且无点位叙事
- 现状 Leaflet 高德地图（平面），已有点位与连线，值得保留；设计稿要求升级为"三维高邮湖地图"，点击点位弹出"这里发生过什么故事"。

### 5. 缺游戏与研学入口板块
- 设计稿要求设计"互动游戏"板块（小小水利师/稻田守护者/高邮歌谣）点击跳转对应游戏；现状完全缺失。

### 6. 底部缺行动号召
- 设计稿要求底部：夕阳湖景背景 +「遗产并非停留在过去，而是在今天继续生长」+ 加入守护计划 / 关注公众号 / 分享高邮故事三个可点击按钮。

### 7. 站名与仓库
- 设计稿第 10 条：站点名/仓库名 denghui 应改为 **meiligaoyou**（如 `meiligaoyou.github.io`）。

## 三、具体实施方案

### 阶段一：首页 1:1 重构（最高优先级）
在现有代码基座上重建 `index.html` 首屏与全页结构，严格对照上图：

1. **顶部导航**：固定顶栏，白/米色半透明，含 7 个菜单项（首页/探索高邮/遗产地图/文化故事/研学路线/互动游戏/数字展厅），锚点或独立页面。
2. **Hero 首屏**：
   - 背景：选用 `高邮照片` 中的实拍图（如 `高邮航拍1.jpg` / `高邮湖6.jpg`）做全屏背景，叠加深绿→浅绿渐变遮罩，保留水墨质感。
   - 主标题「遗产融绘」「魅力高邮」用毛笔书法风格（引入中文书法字体/字库），金色描边，居中。
   - 副题「高邮湖泊湿地多类型遗产 · 数字活化平台」，标语「一湖水·一片田·一方人」「探索千年湿地文明」。
   - 金色描边按钮「开启高邮遗产之旅」→ 点击触发水波涟漪 + 页面卷轴向下展开。
   - 装饰：右侧仿印章（红章「魅力高邮」）、左侧竖排诗句「一湖水·润泽千年；一方田·孕育智慧；一群人·守护传承」。
3. **三脉卡片（一湖三脉）**：三列卡片，圆形图标（水=蓝/波浪、田=绿/稻穗、人=橙/民歌），每卡：大标题 + 遗产名片 + 简介 + "点击了解"。
   - 水之源：里运河—高邮灌区、车逻闸、南关坝、平津堰、子婴闸；文案"水，是高邮文明的起点"。
   - 田之魂：稻鸭鱼蟹复合生态系统、四季变化（春播种/夏共作/秋丰收/冬传承）；文案"一粒米背后，是千年的生态智慧"。
   - 人之韵：高邮民歌、咸鸭蛋制作技艺、渔文化；文案"人，是遗产真正的守护者"。
4. **穿越千年时间轴**：横向长卷，古代（水利建设/运河交通/农业生产形成）→ 近现代（乡村生活/渔业发展/技艺传承）→ 今日（农遗保护/灌区遗产保护/数字化活化），配历史图+实拍图混排。
5. **高邮湖数字地图**：复用现有 Leaflet 点位数据（11 处），保留湖泊多边形与水脉连线；升级为"数字地图 + 点位故事弹窗"，后续可叠加 3D（CSS3D / three.js 或 ECharts GL）过渡。
6. **研学路线**：手绘风路线图（湖→农业基地→古闸→非遗工坊），三条路线卡片（水脉寻踪/稻田密码/湖畔人家），各配实拍小图。
7. **互动游戏中心**：三个游戏入口卡片（小小水利师/稻田守护者/高邮歌谣），点击跳转对应游戏页面（先做入口，游戏后续接入）。
8. **底部 CTA**：深色横幅（可用夕阳/渔村归航实拍图），标语 + 三按钮（加入守护计划→表单/关注；关注公众号→公众号二维码弹窗；分享高邮故事→分享海报页）。

### 阶段二：全站信息架构与文案规范
- 新增/改造页面（或锚点区块）：探索高邮、遗产地图、文化故事、研学路线、互动游戏、数字展厅。
- **文案去"项目"化**：全局替换「项目简介」→「关于高邮」/「平台介绍」；删除一切"新文科大赛/文史哲组/融绘贯通（比赛名）"字样；「实地调研数据分析」→「现状」；「项目成果」→「数字成果」/「活态成果」。
- 站名/标题统一为「遗产融绘 · 魅力高邮」。

### 阶段三：视觉体系升级
- 字体：主标题引入毛笔书法字体（如 站酷/文悦 古体字，或 Web 字体）；正文保留 Noto Serif SC / 思源宋体。
- 配色令牌：深湖绿 #1a3a2a、浅绿 #e8f0e4、米黄 #faf6ee、金色 #b8860b、墨色 #2b2b2b，统一 CSS 变量。
- 装饰：水波纹 SVG、印章、纹样边框、竖排文字、云纹；滚动时水波/卷轴动画。
- 用实拍照片替换抽象占位（素材见 `高邮照片/高邮照片/`）。

### 阶段四：技术实施与部署
- **基座建议**：继续用 `gaoyou-pages`（纯 HTML/CSS/JS + GitHub Pages 静态部署，打开即用、评审演示最稳）；`gaoyou-website`（React）作为后续深度交互/3D 的演进版。
- 仓库名改为 `meiligaoyou`（`https://meiligaoyou.github.io`），favicon/title/meta 同步。
- 照片压缩后入库（现状图片平均 200KB–1MB，首屏需压缩到 ≤300KB）。
- 交互游戏先做可演示的轻量版本（如「小小水利师」闸门调节 H5 小游戏）。

### 阶段五：评审指标对标（为什么这样做能加分）
- 选题意义/问题导向：网站作为"数字活化平台"回应"文化疏离/阐释断裂/代际断层"三重困境——首页三脉结构直观呈现"水—田—人"共生关系，直击调研发现的 53.95% 灌区认知空白。
- 实践过程：网站所用点位、照片、数据全部来自 2025.08/2026.01 两次实地调研（215 问卷/10 访谈/800+ 照片），首页显著位置标注"数据来源与实地调研"即可证明真实实践。
- 创新点：三维数字地图 + 沉浸式叙事 + 互动游戏 + 研学路线，是"数字技术运用"的实打实成果。
- 可操作性：单文件静态站可复现、可迁移，作为"可复制范式"的交付物。

## 五、总结

> 一句话：**把"给评委看的项目汇报页"改造成"给公众逛的数字博物馆平台"——首页严格照微信图片 1:1 还原，全站去掉"比赛/项目"痕迹，用真实调研照片和数据做支撑，把网站做成"水—田—人"共生叙事的沉浸式入口。**

1. 当前网站的最大问题是**定位错位**（汇报味过重），与设计稿"数字活化平台"定位冲突，这是首先要改的。
2. 微信图片已给出**完整的首页蓝图**：导航、水乡 Hero、三脉、时间轴、数字地图、研学、游戏、守护 CTA，逐区块可 1:1 还原。
3. 资产已备齐：实拍照片（高邮湖/灌区/渔村/大运河/高邮鸭）、调研数据（215 问卷等）、地图点位（11 处），无需从零造内容。
4. 实施顺序：先首页还原（最高优先、评审一眼可见），再全站信息架构，最后深度交互（3D 地图、游戏）作为加分项。
5. 改完的效果：首页与图片一致 → 一眼是"高邮文化的数字长卷"而非"比赛作品"，同时网站本身成为项目的核心成果交付物，支撑"数字技术运用"与"可操作性"两个评审维度。
