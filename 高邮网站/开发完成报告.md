## 一、项目概况

### 设计目标
- **原定位**: 项目汇报风格网站
- **目标定位**: 多类型遗产数字活化平台（数字博物馆）
- **核心理念**: 以"水—田—人"的共生关系为叙事主线，展示高邮湖泊湿地三类遗产的融合

### 改进需求（来自设计稿）
1. ✅ 首屏需改为沉浸式数字博物馆风格（而非项目汇报风）
2. ✅ 消除"新文科大赛"、"项目"等关键词
3. ✅ 实现三脉结构（水之源/田之魂/人之韵）
4. ✅ 建立完整的信息架构（导航、时间轴、地图、研学、游戏等）
5. ✅ 采用古典设计风格（毛笔书法、水纹纹样、打印风格）

## 四、核心创新点

### 1. 数字地图交互
- **3D倾斜视角**：45°俯瞰视角，支持投影旋转
- **标签碰撞避让**：自动隐藏重叠标签，hover显示
- **多源底图切换**：卫星影像 ⇄ 高德街景地图
- **GeoJSON可视化**：湖面+水脉+农田+村落区域分层显示
- **飞入动画**：滚入地图时自动从全景飞向高邮湖区

### 2. 三脉卡片动画
- **水流动画**：流体纹理 + 水平滚动
- **四季轮转**：🌱→🌾→🍂→❄️ 循环动画
- **灯火歌声**：音符浮起粒子效果，模拟民歌意象

### 3. 数据故事化
- **柱形图对比**：本地认知 vs 外界认知差异可视化
- **环形图分层**：灌区认知"四层断层"展示
- **问卷数据实时化**：215份问卷、10人访谈、800+图片实际调研数据

### 4. 响应式细节
- **自适应布局**：Hero区块、卡片网格、地图高度在手机/平板/桌面下自适应
- **性能优化**：LazyLoad就绪、外部库异步加载备选方案
- **辅助功能**：ARIA标签、键盘操作支持

## 十、快速开始指南

### 本地运行
```bash
# 1. 进入项目目录
cd d:\新文科比赛\高邮网站\gaoyou-pages

# 2. 启动HTTP服务器
python -m http.server 8888

# 3. 打开浏览器
访问 http://localhost:8888/index.html
（会根据窗口宽度自动跳转到桌面版或手机版）
```

### 部署到GitHub Pages
```bash
# 1. 创建新仓库：meiligaoyou
# 2. 本地克隆
git clone https://github.com/YOUR_USERNAME/meiligaoyou.git
cd meiligaoyou

# 3. 将gaoyou-pages中的所有文件复制到仓库根目录
# 4. 提交并推送
git add .
git commit -m "Initial commit: Gaoyou Heritage Digital Platform"
git push origin main

# 5. 在GitHub仓库Settings→Pages中启用GitHub Pages
# 完成！自动发布至 https://YOUR_USERNAME.github.io/meiligaoyou
```
