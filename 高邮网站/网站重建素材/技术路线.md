# 技术路线

## 一、总体技术架构

本项目以高邮湖泊湿地多类型遗产的数字化保护与活化利用为目标，采用"数据采集与建库—前端交互与展示—后端管理与接口—沉浸式体验拓展"四层递进的技术架构。各模块之间通过统一的数据规范和接口协议实现前后端解耦与协同。

整体技术路线如下：

```
数据采集与建库                前端交互展示                 后端管理与接口               沉浸式体验拓展（规划中）
──────────────            ──────────────            ──────────────              ─────────────────
实地调研采集              IP门户网站                  数据库与管理系统              互动叙事游戏
· 215份问卷               · HTML5+CSS3+JS            · SQLite/MySQL              · HTML5 Canvas 游戏
· 10人次访谈              · MapLibre GL 3D地图        · RESTful API 接口           · 微信小程序
· 800+张照片              · ECharts 数据看板          · 数据分类检索                · LBS定位打卡
· GIS空间数据             · 响应式多端适配            · 问卷数据统计分析             · 线上线下联动
```

## 二、已开发完成的技术模块

### IP门户网站（已完成）

门户网站是本项目的核心数字载体，已完成全部页面开发，采用纯静态部署方案。

**前端技术栈：**
- HTML5 + CSS3 + 原生JavaScript（无框架依赖）
- MapLibre GL 4.7.1 —— 3D交互式地图，实现45度俯瞰视角、卫星/街景底图切换、11处遗产点位标注、标签碰撞避让算法、点位信息弹窗
- ECharts 5.4.3 —— 4张数据可视化图表（认知分化柱状图、灌区断层环形图、技艺差异分组图、价值认同比例图），数据来源于215份实地调研问卷
- CSS变量系统管理配色（深湖绿 #2d6a4f / 金色 #b08a3e / 米黄 #faf6ec），3个响应式断点（520px/700px/900px）
- 本地书法字体（思信凯体/字芒行）+ CDN加载Ma Shan Zheng / Noto Serif SC，实现毛笔书法标题视觉
- CSS Keyframe动画系统，实现水流纹理、四季轮转、音符粒子等三脉卡片交互动效

**页面结构（单页应用路由）：**
首页门户 → 探索高邮（三脉卡片） → 遗产地图 → 现状数据 → 文化故事（时间轴） → 研学路线 → 互动游戏中心 → 数字展厅 → 关于我们

**部署方案：**
纯静态文件部署至GitHub Pages，通过设备宽度智能检测自动切换桌面版（index.html）与手机版（index-m.html）。

## 三、正在建设的技术模块

### 数据库与数据分类管理系统

基于SQLite/MySQL搭建高邮遗产结构化数据库，支撑门户网站数据展示、问卷统计分析与后续功能扩展。

**数据库结构（共14张业务表）：**

| 表名 | 用途 | 已录入数据 |
|------|------|-----------|
| heritage_vein | 遗产三脉分类（水之源/田之魂/人之韵） | 3条 |
| heritage_site | 11处遗产点位（含经纬度坐标、遗产级别、朝代） | 11条 |
| timeline_event | 穿越千年时间轴事件 | 9条 |
| survey_questionnaire | 调研问卷基础信息（215份） | 待录入 |
| survey_question | 问卷题目定义（李克特量表维度） | 10题 |
| survey_answer | 问卷逐题回答明细 | 待录入 |
| interview_record | 10人次深度访谈记录 | 待录入 |
| survey_photo | 800+张调研照片元数据 | 待录入 |
| study_route | 3条研学路线（水脉寻踪/稻田密码/湖畔人家） | 3条 |
| route_stop | 路线途经点明细 | 待录入 |
| game | 互动游戏信息（3款） | 3条 |
| gallery_photo | 数字展厅16张精选照片 | 16条 |
| stat_summary | ECharts图表数据源（JSON格式） | 4张图表 |
| visit_log | 网站访问日志统计 | 待运行采集 |

**关键表关系：**
- heritage_site 通过 vein_id 关联 heritage_vein，实现按脉络筛选遗产点
- survey_answer 关联 survey_questionnaire 和 survey_question，支撑问卷数据的交叉分析
- route_stop 关联 study_route 和 heritage_site，实现研学路线与遗产点位的空间关联

**后续扩展方向：**
- 接入Spring Boot后端，将SQLite迁移至MySQL，提供RESTful API接口
- 实现Elasticsearch全文检索，支持遗产名称、关键词的模糊搜索
- 开发管理后台，实现遗产数据的增删改查与分类管理
- 问卷数据从Excel批量导入，自动生成ECharts可视化图表

## 四、规划中的技术模块

### 互动叙事游戏（规划中）

以高邮湖泊湿地遗产为叙事背景，开发轻量级HTML5网页游戏，嵌入门户网站的"互动游戏中心"板块。

**技术方案：**
- 游戏引擎：HTML5 Canvas + Phaser.js（轻量级2D游戏框架），零安装即玩
- 已上线："小小水利师"游戏，以里运河-高邮灌区为背景
- 筹备中："稻田守护者"（农业遗产主题）、"高邮歌谣"（非遗主题）
- 数据存储：游戏进度通过浏览器本地存储（localStorage）暂存，后续对接后端实现多端同步

### 线下研学体验联动（规划中）

将线上数字平台与线下实地研学体验相结合，实现线上线下数据互通。

**技术方案：**
- 微信小程序（微信开发者工具 + WXML/WXSS/WXS）
- 高德定位SDK实现LBS定位与打卡签到，通过坐标围围栏算法判断用户是否到达研学路线途经点
- 待用户到达指定遗产点位后，通过微信小程序推送该点位的历史故事、文化知识等内容
- 用户学习进度与打卡记录同步至后端数据库（survey_questionnaire / visit_log 表结构可扩展支持）

## 六、关键数据说明

本项目全部技术开发基于扎实的实地调研数据：
- **215份有效问卷**：覆盖高邮湖周边核心区、缓冲区、外围村落村民，有效回收率90.7%
- **10人次深度访谈**：涵盖高宝邵伯湖渔业管理处、高邮市水利局、江苏高邮鸭发展集团等政府部门与企业
- **800+张实地调研照片**：涵盖遗产景观、生产活动、民俗文化、工程设施等类别
- **11处遗产点位**：含5座闸口/水坝、1个灌区、1个湖泊、1个农田、1个村落、2个非遗传承场所
- **3条研学路线**：水脉寻踪（12.5km）、稻田密码（8km）、湖畔人家（10km）
