## 三、新旧网站结构对比

### 当前网站（9 个板块）
```
首页 → 探索高邮（三脉卡片） → 遗产地图 → 现状数据 → 文化故事（时间轴）
→ 研学路线 → 互动游戏中心 → 数字展厅 → 关于我们
```

### 新设计文档（9 个板块，内容大幅扩展）
```
首页（全新文案） → 一、水之源 → 二、田之魂 → 三、人之韵 → 四、穿越千年
→ 五、高邮湖数字地图 → 六、研学路线 → 七、互动游戏中心 → 关于我们
```

### 核心差异

| 方面 | 当前网站 | 新设计文档 |
|------|---------|-----------|
| 主题名 | "遗产融绘·魅力高邮" | "数绘湖田" |
| 结构主线 | 三脉（水/田/人）分散卡片 | "水之源→田之魂→人之韵"三大板块深度展开 |
| 内容量 | 概括性介绍 | 极大量新增文本（每板块数百字详细叙述） |
| 水之源 | 简单地图标注 | 新增灌溉遗产详述、归海五坝故事、灌区管理 |
| 田之魂 | 简单卡片 | 新增稻鸭鱼蟹互动、鸭品种、特色农业技术 |
| 人之韵 | 简单时间轴 | 新增音频交互、鸭蛋制作时间轴、翻转卡片、节庆日历 |
| 地图 | MapLibre 2D | 改为三维交互地图（Workbuddy平台） |
| 游戏 | HTML5 Canvas | 改为 Unity 开发（规划中） |

## 四、更新步骤（按顺序执行）

### 第⑦步：首屏标题更新 ⭐ 立即可做

**难度**：⭐ | **预计时间**：10 分钟

- 修改 `index.html` 和 `index-m.html` 的 hero 区域
- 标题：「遗产融绘·魅力高邮」→「数绘湖田·魅力高邮」
- 副标题更新为新设计文档文案
- 更新导航栏 logo 文字
- 更新 `<title>` 标签
- 背景图暂用现有的，后续美化

### 第⑧步：首页导语更新

**难度**：⭐ | **预计时间**：15 分钟

- 替换首页介绍段落为新文案
- 核心要点：
  - 「这里是高邮」开篇
  - 高邮湖 780km²、一湖两河三堤
  - 「双世界遗产」城市
  - 七千年农耕文明，一千二百年灌溉史
  - 欢迎走进「数绘湖田·魅力高邮」

### 第⑨步：板块一「水之源」更新

**难度**：⭐⭐⭐ | **预计时间**：1-2 小时

三大子内容：
1. **高邮湖灌溉遗产** — 平津堰、归海五坝（含开坝与保坝历史抉择）、南关坝、车逻坝等详细介绍
2. **水文水系历史演变** — 龙虬庄→平津堰→南北水关→减水坝→归海五坝五段历史
3. **灌区水利管理** — 产学研合作、数字孪生灌区、制度保障、水文化传承

**交互设计**：
- 新增归海五坝「开与不开」的历史抉择故事
- 需要：闸坝类实拍照片（车逻闸、南关坝等 — 已有素材）

**已有素材**：车逻闸 33 张、南关坝 33 张、运河故道 42 张、高邮灌区相关

### 第⑩步：板块二「田之魂」更新

**难度**：⭐⭐⭐ | **预计时间**：2-3 小时

四个子板块：
1. **稻鸭鱼蟹共生探索** — 可交互分层示意图（稻/鸭/鱼/蟹四要素点击展开）
2. **农业文化遗产荣誉展示** — 2017 年入选、首个以水为主体、全球候选
3. **高邮鸭品种展示** — 品种概况、养殖模式、种质保护（3 个 tab）
4. **特色农业技术** — 稻作耕种、水产养殖、鱼类混养、鱼虾蟹混养、鱼鹰捕鱼（5 个 tab）

**已有素材**：高邮鸭育种基地 51 张、高邮青虾 32 张

### 第⑪步：板块三「人之韵」更新

**难度**：⭐⭐⭐⭐ | **预计时间**：3-4 小时

三大子内容 + 四个交互区：
1. **非遗技艺** — 高邮民歌（国家级）、咸鸭蛋制作（省级）、其他非遗
2. **人文环境** — 鸭的一生陪伴、歌与戏、谚语文化、水神信仰
3. **风物人情** — 咸鸭蛋与全鸭宴、七公会、双黄鸭蛋节、邮文化节等节庆

**交互区（后续补充）**：
- 「听·高邮」音频播放器（民歌《数鸭蛋》）
- 「品·高邮」鸭蛋制作时间轴
