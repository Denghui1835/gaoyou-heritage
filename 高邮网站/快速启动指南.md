## 🔧 常见问题排查

### 问题1: 地图显示为空或加载失败

**症状**: 地图区域显示白色或报错

**解决方案**:
1. 检查网络连接
2. 检查浏览器控制台是否有错误信息
3. 等待瓦片加载（可能需要5-10秒）
4. 尝试刷新页面
5. 如持续失败，可能是高德地图CDN超时

### 问题2: 手机版自动跳转问题

**症状**: 在桌面浏览器中仍然打开手机版

**原因**: 浏览器窗口宽度 ≤768px

**解决方案**:
- 放大浏览器窗口
- 或在URL后添加 `#desktop` 强制使用桌面版
  ```
  http://localhost:8888/index.html#desktop
  ```

### 问题3: 图片无法加载

**症状**: 图片位置显示为破图标

**解决方案**:
1. 确认 `img/` 文件夹中的图片文件存在
2. 检查文件名是否正确（区分大小写）
3. 清除浏览器缓存（Ctrl+Shift+Delete）

### 问题4: 字体显示不正确

**症状**: 毛笔标题显示为默认字体

**解决方案**:
1. 等待Google Fonts加载（可能需要2-3秒）
2. 检查 `fonts/` 文件夹中的 `stxingkai.woff2` 是否存在
3. 刷新页面重新加载资源
