# 《小小水利师 · 高邮灌区》基础版

> 融绘贯通——多类型遗产系统性保护 项目 · 互动游戏（Ren'Py 8.5）

用 Ren'Py 制作的调水决策叙事小游戏：玩家扮演里运河—高邮灌区的实习水利员，在「春·开闸引水」「夏·水田分账」「秋·大旱调度」三关里做出调水决策，读懂的正是世界灌溉工程遗产「水—田—人」共生体系。

## 玩法
- 序章 → 3 次决策（选项决定得分与结局）→ 结局结算 → 遗产知识卡片
- 每关都有「对 / 错」两个方向，错误选项也会得到老水伯的解释——寓教于错

## 如何打开
- 方式一（推荐）：打开 Ren'Py Launcher（`D:\RenPy\renpy.exe`），在项目列表选中「小小水利师 · 高邮灌区」→ 启动项目
- 方式二（命令行）：`D:\RenPy\renpy.exe "D:\新文科比赛\高邮网站\互动游戏\小小水利师"`

## 结构

## 已内置的遗产知识
- 里运河—高邮灌区 2021 年入选「世界灌溉工程遗产」，全国首个依托运河的世界灌溉工程遗产
- 「蓄水—调水—配水」体系、西堤三闸与运堤闸洞
- 平津堰（唐）、南关坝（明）、车逻闸（明/清）等活态水利工程
- 「稻鸭鱼蟹」立体共作与生态循环
